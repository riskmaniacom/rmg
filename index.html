🔑 API 연결 설정
네이버 또는 NewsAPI로 기사를 수집하고, Claude API로 금융 리스크 관점 요약을 생성합니다.
작동 방식
네이버 뉴스 API 또는 NewsAPI → 키워드로 기사 수집 → Claude API → AI 요약 → Daily 브리핑 자동 생성
⚠️ 네이버 API는 CORS 프록시가 필요합니다. NewsAPI는 직접 호출 가능합니다.
🟢
네이버 검색 API
developers.naver.com — 국내 뉴스 (한국어)
미설정
발급: developers.naver.com/apps → 앱 등록 → 검색 API 체크
네이버 API 전용. 운영 환경에서는 자체 백엔드 서버 권장.

🏷️ 뉴스 검색 키워드
등록된 키워드로 네이버 뉴스를 검색합니다. 한국어 키워드를 권장합니다.
🚀 뉴스 자동 수집 → AI 요약 → 브리핑 생성
등록된 키워드로 뉴스를 검색하고, Claude AI가 금융 리스크 관점에서 각 기사를 요약하여 오늘의 Daily 브리핑을 자동으로 생성합니다.
